### ۲.۱ سخت‌سازی دسترسی‌های دیتابیس در محیط پروداکشن (Database Least Privilege)
پس از اجرای مایگریشن‌ها در محیط استقرار، دسترسی‌های ویرایش روی دفاتر کل لجر سلب می‌شود:

```sql
-- اجرای دستورات دسترسی محدود روی کاربر اپلیکیشن (app_user)
REVOKE UPDATE, DELETE ON finance.journals FROM app_user;
REVOKE UPDATE, DELETE ON finance.journal_entries FROM app_user;
REVOKE UPDATE, DELETE ON finance.ledger_blocks FROM app_user;
REVOKE UPDATE, DELETE ON integration.evidence_chain FROM app_user;
REVOKE UPDATE, DELETE ON integration.critical_event_receipts FROM app_user;
REVOKE UPDATE, DELETE ON risk.risk_decisions FROM app_user;

-- کاربر صرفاً اجازه INSERT و SELECT روی جداول ممیزی و مالی دارد
GRANT SELECT, INSERT ON finance.journals TO app_user;
GRANT SELECT, INSERT ON finance.journal_entries TO app_user;
```

### ۲.۲ اتصال خزانه‌داری واقعی TON Mainnet و کلیدهای سخت‌افزاری KMS
* **آدرس والت Mainnet:** والت خزانه به صورت امن در متغیر `TREASURY_ADDRESS` ست می‌شود.
* **کف ذخیره امنیتی:** `SAFETY_RESERVE_ATOMIC` برابر با حجم پیش‌بینی‌شده برای پوشش کارمزدهای گس شبکه قرار می‌گیرد.
* **KMS Key ID:** پارامتر `TON_SIGNER_REFERENCE` به کلید سخت‌افزاری متصل می‌گردد (`aws-kms://arn:aws:kms:...`).

### ۲.۳ مانیتورینگ، قوانین هشدار و حد آستانه (Alerting Thresholds)

```yaml
# Prometheus Alertmanager Production Rules
groups:
  - name: goldpay_production_slo_alerts
    rules:
      - alert: LedgerImbalanceCritical
        expr: goldpay_ledger_balanced == 0
        for: 0m
        labels:
          severity: CRITICAL
        annotations:
          summary: "Global double-entry balance mismatch detected"
          description: "Debits != Credits across ledger. Financial operations frozen."

      - alert: PayoutWaitingLiquidityStall
        expr: goldpay_payouts_waiting_liquidity_count > 0
        for: 30m
        labels:
          severity: HIGH
        annotations:
          summary: "Payouts stranded in WAITING_LIQUIDITY"
          description: "Treasury spendable liquidity is below requested payout volumes."

      - alert: OracleDivergenceHigh
        expr: goldpay_oracle_divergence_bps > 500
        for: 5m
        labels:
          severity: WARNING
        annotations:
          summary: "Exchange rate divergence exceeds 5%"
          description: "CEX and DEX market price sources diverged beyond safety threshold."

      - alert: PaymentVerificationLag
        expr: goldpay_payment_verification_lag_seconds > 600
        for: 5m
        labels:
          severity: HIGH
        annotations:
          summary: "Invoices stuck in CREATED state past TTL"
          description: "Scheduled polling is attempting recovery for delayed callbacks."
```
